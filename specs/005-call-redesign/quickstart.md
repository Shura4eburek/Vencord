# Quickstart: проверка редизайна

## Автотесты

```bash
npx tsx --test src/userplugins/p2pCall/*.test.ts
pnpm testTsc
pnpm lint
```

Что проверяют тесты:
- `tabs.test.ts`:
  - одного звонка нет — вкладок нет;
  - активна вкладка звонка, начатого последним;
  - ручной выбор держится и сбрасывается, когда один звонок пропал;
  - при равных временах активна P2P.
- `tileColor.test.ts`:
  - средний цвет непрозрачных пикселей;
  - прозрачная картинка даёт `null`.
- `patches.test.ts`: `renderCall` завёрнут, вызывается ровно один раз.
- `icons.test.ts`: все пути валидны.

## Ручная проверка (два ПК: A, B)

| # | Действие | Ожидается |
|---|---|---|
| 1 | P2P-звонок A ↔ B | шапка с именем, две плитки цветом аватарки, аватарка по центру, круглые кнопки снизу |
| 2 | B выключает микрофон, потом говорит A | у B бейдж mic-off, у A зелёная обводка |
| 3 | наведение на плитку | внизу слева имя |
| 4 | A включает камеру, потом демку | видео на плитке; у демки «В эфире», кнопка демки зелёная, клик открывает поповер качества |
| 5 | шеврон микрофона → другое устройство ввода | B слышит A с нового микрофона без переподключения |
| 6 | шеврон микрофона → другой вывод | звук B идёт в новое устройство |
| 7 | шеврон камеры → другая камера | B видит другую камеру |
| 8 | «На весь экран», затем Esc | область на весь экран и обратно |

| 11 | завершить звонок Discord | вкладки пропали, P2P-область как в п. 1 |
| 12 | «Добавить в звонок» → третий друг | ему звонит, как кнопка в шапке ЛС (групповой звонок, specs/004) |

| 14 | входящий звонок, в том числе во время звонка | модалка по дизайн-системе; три кнопки во время звонка |
| 15 | светлая тема Discord | цвета темы, сцена чёрная, текст читается |
| 16 | узкое окно (< 620px и < 440px) | кнопки 46px; боковые кнопки скрыты |
