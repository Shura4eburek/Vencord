# Contracts: обновления

## 1. Ассеты релиза

| Ассет | Кто читает |
|---|---|
| `patcher.js`, `preload.js`, `renderer.js`, `renderer.css`, `manifest.json`, `manifest.sig` | старые копии (формат без изменений) |
| `p2pcall-net.js`, `manifest-v2.json`, `manifest-v2.sig` | новое автообновление |
| `P2PCall-Vencord.zip` | ручная установка (кладёт все 5 файлов) |

`manifest-v2.json`: `{ "schema": 2, "version": "2026.10.18-3", "files": { "<имя>": "<sha256>", … } }`, подпись ed25519 тем же ключом.

## 2. IPC `checkForUpdate` (main)

Вход: — . Выход: `UpdateResult` (data-model). Скачиваются и подменяются только файлы, у которых sha256 на
диске ≠ манифесту; все скачанные проверяются до подмены (как сейчас). `p2pcall-net.js` подменяется
через временный файл и `rename` — загрузчик увидит новый `mtime`.

## 3. Тексты для пользователя (рендерер)

| Итог | Уведомление | Кнопка | Текст кнопки «Проверить обновление» |
|---|---|---|---|
| `none` | «P2PCall обновлён до X — ничего делать не нужно» | — | «Обновлено (X), ничего делать не нужно» |
| `reload` | «P2PCall обновлён до X. Нажми, чтобы перезагрузить окно» | `location.reload()` | «Обновлено (X) — перезагрузи окно» |
| `restart` | «P2PCall обновлён до X. Нажми, чтобы перезапустить Discord» | `relaunchDiscord()` | «Обновлено (X) — перезапусти Discord» |
| `latest` + `pending` | как у `pending` без «обновлён до» | как у `pending` | «Уже последняя версия — но нужно …» |

Во время звонка уведомление откладывается до `idle`/`ended`.
