# Quickstart: проверка обновлений

## Автотесты

```bash
npx tsx --test src/userplugins/p2pCall/*.test.ts
pnpm testTsc
```

- `updateLogic.test.ts`: `PART_OF`/`strongest`, `parseManifestV2` (ровно 5 файлов, schema 2), прежний `parseManifest` не изменился;
- `updateRun.test.ts`: фейковый релиз в temp-dist — изменился только `renderer.js` → `reload`, скачан только он;
  только `p2pcall-net.js` → `none`; `patcher.js` + `renderer.js` → `restart`; ничего → `latest`; pending restart
  сохраняется при следующем `none`; неверная подпись v2 → ошибка, ничего не подменено;
- `netLoader.test.ts`: модуль перезагружается при новом mtime без активного туннеля, не перезагружается с
  активным, битый файл → прежний модуль + `broken`.

## Ручная проверка (установка из zip, не репозиторий)

| # | Действие | Ожидается |
|---|---|---|
| 1 | Поставить релиз A, затем выпустить B с правкой только в `ui/` | «перезагрузи окно»; после кнопки — версия B в настройках |
| 2 | Выпустить C с правкой только в `upnp.ts` | «ничего делать не нужно»; следующий звонок пишет в лог новую строку из C |
| 3 | Выпустить D с правкой в `native.ts` | «перезапусти Discord» |
| 4 | Во время звонка «Проверить обновление» с новым релизом | звонок не рвётся; уведомление после сброса |
| 5 | Старая копия (до фичи) обновляется | «перезапусти Discord»; после перезапуска через ≤ 15 с докачан `p2pcall-net.js`, туннель работает |
