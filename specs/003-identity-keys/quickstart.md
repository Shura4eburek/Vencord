# Quickstart: ключи и контакты

## Автотесты

```bash
npx tsx --test src/userplugins/p2pCall/*.test.ts
pnpm testTsc
```

- `cpace.test.ts` — векторы драфта CPace (ristretto255/SHA-512); одинаковый пароль → один ISK, разный → разный; точка-ноль отвергается;
- `pairing.test.ts` — два участника в памяти: обмен завершается и даёт одинаковые ключ пары и код проверки; чужой `channelId` → контакта нет;
  подделанный `from` → нет; повтор `pake1` сверх лимита игнорируется; новый ключ известного контакта → `pending`;
- `signaling.test.ts` — `ring` контакту с подсказкой ключа пары доходит; сообщение прежней схемы от пользователя с контактом отброшено; без контакта прежняя схема работает;
- `contacts.test.ts` — сохранение/загрузка, удаление, подтверждение устройства.
