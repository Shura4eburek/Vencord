# P2PCall UI — звонок как у Discord

Дата: 2026-10-05
Статус: дизайн согласован, ждёт ревью спеки
Основа: `2026-10-04-p2p-call-design.md` (транспорт, сигналинг, медиа — без изменений)

## Цель

Убрать плавающую панель и кнопку в панели ввода. Встроить P2P-звонок в интерфейс Discord так, чтобы
он выглядел и вёл себя как обычный звонок в ЛС:

- кнопка «трубка + цепь» в шапке ЛС рядом с обычными кнопками звонка;
- область звонка над сообщениями ЛС;
- плашка «P2P подключено» над панелью аккаунта;
- модалка входящего звонка по центру.

**Критерий успеха:** в двух клиентах весь цикл звонка (вызов, ответ, разговор с подсветкой говорящего,
камера, экран, deafen, переход в другой канал и обратно, сброс) проходит без плавающих окон и без
кнопки в панели ввода.

## Не делаем (YAGNI)

- Поп-аут окна звонка.
- Регулировка громкости собеседника через ПКМ.
- Групповые звонки.
- Использование настоящих компонентов звонка Discord (`ChannelCall`): они завязаны на нативный движок.

## Точки встраивания

Проверены по бандлу discord.com от 2026-10-05 (чанк с ЛС — `8287e37da317f9ca.js`, панель аккаунта —
`6c4eab526ebbcc36.js`).

### Патч A — кнопка в шапке ЛС

- `find`: `location:"PrivateChannelCallButton"`
- В `render()` класса кнопок звонка: `children:[this.renderVoiceCallButton(),this.renderVideoCallButton()]`.
- Одна регулярка захватывает компонент иконки шапки из `(0,\i.jsx)(<HeaderBar>.Icon,{ref:this.iconRef`
  и дописывает третий элемент: `$self.renderHeaderButton(this.props.channel, <HeaderBar>)`.
- Кнопка рисуется `<HeaderBar>.Icon` — размер, ховер и подсказка как у родных.

### Патч B — область звонка

- `find`: `"Missing channel in Channel.renderCall"`
- В начало `renderCall(){let{channel:X}=this.props;` вставляется
  `if($self.isP2PChannel(X?.id))return $self.renderCallArea(X,this.props.height-200);`.
- Перед реализацией проверить, что `renderCall()` вызывается из `render()` безусловно (а не только
  при `showCall`). Если нет — патчить место вызова.

### Патч C — плашка над аккаунтом

- Та же точка, что у `spotifyControls`: `find` `#{intl::USER_PROFILE_ACCOUNT_POPOUT_BUTTON_A11Y_LABEL}`,
  `match` `/(?<=\i\.jsxs?\)\()(\i),{(?=[^}]*?userTag:\i,occluded:)/`, панель аккаунта оборачивается
  компонентом, который рисует плашку сверху.
- Проверить совместимость с включённым `spotifyControls`. При конфликте — встроиться в обёртку иначе
  (например, рендерить плашку из уже обёрнутого `spotifyControls` элемента через отдельный `match`).

### Входящий звонок

Без патча: модалка Vencord (`openModal` + `Modal` из `@webpack/common`).

## Область звонка (`CallArea`)

- Фон — тёмный сплошной цвет (как у Discord-звонка), не CSS-переменные темы.
- Плитки 16:9 в ряд, по центру; при одном видео — оно крупно, вторая плитка маленькая в углу.
- Панель кнопок по центру снизу: микрофон, звук (deafen), камера, экран, переключатель
  «Плавность/Чёткость» (только при своём экране), сброс (красная).
- Чип в правом верхнем углу: `RTT мс · потери % · напрямую/через ретранслятор` (если `showStats`).
- Высота: по умолчанию 300 px, тянется за нижний край от 160 px до `maxHeight` из патча; значение
  хранится в памяти плагина на время сессии.
- Двойной клик по видео — `requestFullscreen()`.
- Фаза «вызов» — плитка собеседника с пульсирующей обводкой и подпись «Вызов…», кнопка сброса.
- Фаза «соединение» — подпись «Соединение…».
- Фаза «завершён» — 3 секунды подпись с причиной (тексты как в текущем `END_TEXT`), затем область исчезает.

## Поток данных

- `CallController` остаётся единственным источником состояния; `View` расширяется:
  - `deafened: boolean`;
  - `speaking: { self: boolean; peer: boolean; }`.
- `isP2PChannel(id)` — `true`, если `call.channelId === id` и фаза `outgoing | connecting | connected | ended`.
- Входящий: новый хук контроллера `onIncoming()` → `index.tsx` открывает `IncomingCallModal`.
- «Принять с видео»: событие автомата `accept` получает поле `video: boolean`; `start-session` берёт
  его вместо `false`. Обычное «Принять» — `video: false` (ранее согласованная защита: звонящий не может
  включить камеру собеседника).

## Индикатор «говорит»

- На свой микрофон и на звук собеседника вешается `AnalyserNode` (общий `AudioContext` на звонок).
- Раз в 100 мс считается RMS уровня (0..1) и подаётся в `SpeakingDetector`:
  - включение при уровне ≥ `ON = 0.04`;
  - выключение при уровне < `OFF = 0.02` в течение `HOLD_MS = 300`;
  - уровень между порогами состояние не меняет.
- Для своей стороны при выключенном микрофоне или deafen — всегда «молчит».
- `View.speaking` обновляется только при смене значения.

## Deafen

- Включение: `audio.muted = true` для звука собеседника, микрофон выключается; запоминается, был ли
  он включён.
- Выключение: звук собеседника возвращается, микрофон — в запомненное состояние.
- Значок «звук выключен» на своей плитке; собеседнику состояние не передаётся (первая версия).

## Ошибки

| Ситуация | Поведение |
|---|---|
| Патч не применился | Vencord логирует; остальное работает (без A — нет кнопки, входящие принимаются; без B — управление с плашки; без C — нет плашки) |
| Ушёл из ЛС во время звонка | Звонок продолжается, управление на плашке |
| В этом ЛС одновременно идёт Discord-звонок | Рисуется наша область, тост «Идут два звонка: P2P и Discord» |
| Нет доступа к микрофону или камере | Тост с причиной, кнопка зачёркнута |
| Звонящий сбросил, пока открыта модалка | Модалка закрывается, тост «Пропущенный P2P-звонок» |

## Проверка

- **Модульные тесты:**
  - `speaking.test.ts`: включение по порогу, удержание, выключение после `HOLD_MS`, уровень между
    порогами, длинная тишина, шум около порога;
  - `state.test.ts`: `accept` с `video: true` / `false`.
- Существующие 52 теста — зелёные.
- `pnpm testTsc`, `pnpm lint`, `pnpm build`.
- **Скрипт проверки патчей:** регулярки A, B, C прогоняются по скачанному бандлу Discord
  (тем же способом, что в разведке) — у каждой ровно одно совпадение.
- **Ручная проверка в двух клиентах:**
  - кнопка в шапке, Shift+клик;
  - область над сообщениями, подсветка говорящего;
  - deafen;
  - камера, экран, «плавность/чёткость», полноэкранный режим;
  - плашка при переходе в другой канал, клик по имени;
  - модалка: принять, принять с видео, отклонить, звонящий сбросил;
  - сброс с плашки и из области.
