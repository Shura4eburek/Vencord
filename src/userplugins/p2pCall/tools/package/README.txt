P2PCall — прямые звонки в ЛС Discord без серверов Discord (нужен у обоих собеседников)

УСТАНОВКА
1. Распакуй папку P2PCall-Vencord туда, где она будет жить постоянно (например C:\P2PCall-Vencord).
   После установки папку не перемещай и не удаляй — Discord грузит Vencord из неё.
2. Запусти install.cmd. Если Windows SmartScreen ругается — «Подробнее» → «Выполнить в любом случае»
   (это официальный установщик Vencord).
3. Полностью перезапусти Discord: трей → «Выйти», потом открыть снова.
4. Настройки → Vencord → Плагины → включи P2PCall → нажми Ctrl+R.

КАК ЗВОНИТЬ
- Открой ЛС с другом. В шапке справа, рядом с обычными кнопками звонка, иконка «трубка + цепь».
  Клик — голосовой звонок, Shift+клик — с камерой.
- У друга появится окно «Входящий P2P-звонок».
- В углу области звонка: пинг, потери и тип канала. «напрямую» = настоящий P2P.

ОБНОВЛЕНИЯ
- Плагин сам проверяет обновления (при запуске Discord и раз в 6 часов) и скачивает их в эту папку.
  Появится уведомление «P2PCall обновлён» — нажми на него, Discord перезапустится.
- Проверить вручную: Настройки → Vencord → Плагины → P2PCall → «Проверить обновление».

ЕСЛИ ЧТО-ТО НЕ ТАК
- Интерфейс Discord глючит → выключи P2PCall в настройках Vencord и перезапусти Discord.
- Иконка серая «нет связи с сигналингом» → полностью перезапусти Discord (трей → Выйти).
- «Прямое соединение не установилось» → NAT не пробился; пришли Mamoru скрин и логи.
- Удалить всё: uninstall.cmd.
